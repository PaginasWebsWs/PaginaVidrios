# Vidrios Curvos

**Descripción:** Sitio web corporativo para la empresa de vidrios curvos. Desarrollado con Next.js, Tailwind CSS, y TypeScript para una experiencia moderna, rápida y atractiva.

## Características Principales

*   **Diseño Moderno y Responsivo:** Creado con las últimas tendencias de diseño, se adapta a cualquier dispositivo (móvil, tablet, escritorio).
*   **Componentes Reutilizables:** Arquitectura basada en componentes UI (usando `shadcn/ui` y `Radix UI`) para un desarrollo rápido y consistente.
*   **Rendimiento Optimizado:** Construido con Next.js, lo que garantiza un renderizado eficiente y una excelente experiencia de usuario.
*   **Animaciones Suaves:** Integración de `framer-motion` para animaciones elegantes que mejoran la navegación.
*   **Formulario de Contacto Funcional:** Sección de contacto preparada para integrarse con servicios de email (como Resend, o un endpoint de API).
*   **Paleta de Colores y Estilo:** Estilo visual alineado con la identidad de la marca, utilizando `tailwind-merge` y `class-variance-authority` para la gestión de clases.

## Tecnologías Utilizadas

*   **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
*   **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
*   **Estilos:** [Tailwind CSS](https://tailwindcss.com/) con [tw-animate-css](https://github.com/shadcn-ui/tailwindcss-animate)
*   **Componentes UI:** [shadcn/ui](https://ui.shadcn.com/) y [Radix UI](https://www.radix-ui.com/)
*   **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
*   **Manejo de Formularios:** [React Hook Form](https://react-hook-form.com/) con [Zod](https://zod.dev/) para validación
*   **Íconos:** [React Icons](https://react-icons.github.io/react-icons/) y [Lucide React](https://lucide.dev/)
*   **Linting:** [ESLint](https://eslint.org/) con la configuración de Next.js
